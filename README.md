# BPM Tool (Sample Scaffold)

This repository contains a professional scaffold for a BPM (Business Process Management) platform inspired by Camunda.

Goals
- Provide a microservice-based workflow engine and supporting services (task, user) using Java + Spring Boot.
- Include a React-based frontend for a workflow designer and monitoring dashboard.
- Prepare Kubernetes/Helm manifests, Istio integration, and CI/CD pipelines.

Quick start (development)
- Backend: cd backend/workflow-service && mvn test
- Frontend: cd frontend/workflow-designer && npm install && npm start

See /docs for architecture, contributing, and code review rules.
